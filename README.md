# MAK Trading Journal

A personal MEC/USDT trading journal built with React, TypeScript, and Vite.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. For a production check, run `npm run build`.

## Included

- Responsive personal dashboard with profile photo upload
- BUY and SELL transaction logging
- Local browser persistence through `localStorage`
- Portfolio summary, allocation view, and activity chart
- Transaction deletion and CSV export

This is a personal journal. It does not connect to an exchange or provide live balances.
